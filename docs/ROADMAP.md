## 1. 已完成

**工程与基础设施**
- 主控状态机 `scripts/core/main.gd`：TITLE / HUB / RUN / GAMEOVER 四态 + 内置十个命令行入口。
- 全局单例：`Events`（事件总线）、`Game`（元进度 / 存档 / 难度 / 打击停顿）、`Sfx`（程序化合成的 40+ 音效，零外部素材）。
- `RunState`：资源、词条汇总 `recalc()`、六种铳械模块、污染值、结算规则。
- `UpgradeDB`：55+ 条局内词条 + 六种铳械模块，稀有度权重与按层解锁。
- `EventDB`：5 条事件房奇遇（图尔克摊位 / 坏收音机 / 记忆水面 / 茧化残骸 / 裁断信使），
  选项支持代价（盲区币 / 碎片）与代价不足时的禁用提示。
- `UITheme`：配色 + **系统中文字体运行时挂载**（Godot 默认字体不含 CJK，必须走这条路）。
- **UI 键盘可达**（2026-10-16 补缺口）：按钮工厂统一开 `Control.FOCUS_ALL` + 白色焦点描边，各 UI 层打开时自动聚焦第一个按钮，
  W/S 环形移动焦点，Enter / 空格确认，收起界面时释放焦点。修之前标题页、据点五个面板、局内服务面板、暂停菜单、结算页**全都只能点鼠标**。

**战斗**
- 玩家：移动 / 二段跳 / 冲刺 / 剑三段连击 / 蓄力重斩 / 格挡与完美格挡（0.22s）/ 盾击 / 铳与热量 / 幽灵形态 / Q 探测回波。
- **幽灵骇入**：靠近可骇目标起手，按类别抗性决定耗时（机械 0.85 → 异常生物 2.30，精英 ×1.7），
  成功后造成伤害并瘫痪机械/智能体；脱离幽灵形态、拉开距离、能量耗尽三条路径都会中断连接。HUD 有进度条。
- `EnemyDB`：设定文档表 8-1 的 **21 种敌人** 全部建档，五类克制（机械怕电磁、人形怕中毒、异常生物怕灼烧、智能体怕骇入、幽灵体需先探测）。
- `Enemy`：七态行为机（含炮塔 / 飞行 / 蜂群 / 精英），姿态（Poise）与硬直、击退、精英减伤。
- 具名 Boss：三层各一个（B1 织网铆接体 / B3 内环执法者塞勒 / B7 守网者霍尔斯特），共用精英单位放大 + 独立配色 + 专属血条。
- 弹道、命中停顿、屏幕震动、伤害数字、残影、火花、光环、拾取物与磁吸。

**肉鸽循环**
- `Level` 程序化扇区：房间序列（START / COMBAT / ELITE / REWARD / SHOP / REST / EVENT / BOSS）+ 三层平台 + 闸门 + 五套主题配色。

## 3. 关键技术决策

| 决策 | 理由 |
|---|---|
| Godot 4.7.2（`C:\Godot\Godot_v4.7.2-stable_mono_win64\`） | 本机已装；纯 GDScript，不需要 .NET SDK |
| 全代码构建场景，几乎不用 `.tscn` | 手写场景文件易错且不可 diff；代码生成可控、可用 headless 校验 |
| 零外部素材：绘制用 `_draw()`，音效用 `AudioStreamWAV` 合成 | 无美术资源也能先验证手感与循环；仓库里没有二进制资源 |
| 运行时注册输入映射（`InputActions`） | 避免 `project.godot` 里的 InputEvent 序列化文本，且天然支持改键 |
| 碰撞查询用手动 `intersect_shape` / `intersect_ray`，不铺 Area2D | 节点数少、命中逻辑集中、易调 |
| 中文字体运行时从系统加载 | Godot 默认字体无 CJK 字形，会显示为方块 |
| 无头自检一律带 `--quit-after` | 部分流程的退出路径会悬住，不加帧上限时进程可能不退出 |
| 新增 `class_name` 脚本后必须跑 `--import` | 否则全局类名缓存缺失，会报 `Could not find type "..."` |
| 从无类型 Array/Dictionary 取值一律显式标注类型 | `var x := ...` 会报 `Cannot infer the type`；`for x: T in arr` 同理 |
| 读 `const` 字典后要改字段，必须先 `.duplicate(true)` | 否则报 `Invalid assignment on read-only value` |

## 4. 自检与验证

工程内置十个可命令行调用的自检（用法见 `README.md`）：

| 入口 | 覆盖 |
|---|---|
| `--selfcheck` | 标题 → 安全屋 → 五个面板 → 出击 → 翻层 → 死亡 → 回据点 |
| `--combatcheck` | 战斗房刷怪 → 敌人追击 → 玩家掉血 → 清空 → 三选一 |
| `--mapcheck` | 扇区随机性（多 seed 生成对比） |
| `--bosscheck` | 具名 Boss → 元素解锁 → 未肃清不能下潜 → 通关结算 |
| `--elementcheck` | 六种铳元素的伤害/热量通路 |
| `--servicecheck` | 局内售货机 / 维修节点面板 |
| `--pausecheck` | 暂停菜单（确认世界真的停住） |
| `--hackcheck` | 骇入成功 / 瘫痪 / 三路中断 / 抗性表 |
| `--eventcheck` | 事件房生成 → 面板 → 四种效果分支 → 余额不足禁用 |
| `--shot` | 真渲染截图 16 张，落在 `gamemake/_shots/` |

**headless 自检覆盖不到任何 `_draw()`**，所以纯视觉问题只能靠 `--shot` 截图肉眼查。
每次改完画面相关代码，跑一次 `--shot` 再看图。

**自检与玩家存档是隔离的**：自检 / 截图模式下 `Game.save_path` 自动切到
`user://cage_save_selfcheck.json`（`scripts/core/game.gd` 的 `SAVE_PATH_SANDBOX` 与
`is_autotest_run()`），正式游玩的 `cage_save.json` 原样不动。
这条是 2026-10-16 补的：此前两者共用同一个存档文件，跑一次 `--bosscheck` 就会
给玩家账号直接加上 72 碎片、+1 胜场和出击次数。
